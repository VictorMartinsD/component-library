Flexbox Alignment

Uma estrutura flexível demonstrando o uso de alinhamento centralizado e espaçamento dinâmico entre itens internos.

HTML 

<div class="flex-container">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
</div>
CSS 

.flex-container {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 20px;
  
  background-color: var(--input-base);
  border: 1px solid var(--input-stroke);
  border-radius: 12px;
  padding: 30px;
  width: 100%;
  max-width: 600px;
  min-height: 200px;
}

.item {
  width: 80px;
  height: 80px;
  background-color: #212427;
  border: 2px solid var(--brand-light);
  border-radius: 8px;
  display: flex;
  justify-content: center;
  align-items: center;
  color: var(--text-heading);
}
